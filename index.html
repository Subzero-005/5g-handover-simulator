    schoolHow the simulator works

    cell_towerThree radio layers

    4G LTE macro cells on 1.8 GHz cover the whole city. 5G NR mid-band cells on 3.5 GHz use massive MIMO for more capacity. mmWave small cells on 26 GHz carry gigabit speeds but buildings block them almost completely.

    wifiRadio propagation

    Path loss follows the 3GPP TR 38.901 UMa / UMi models. Every building is ray-tested in 3D for line of sight. Shadow fading is spatially correlated, and measurements pass through a layer-3 filter.

    swap_callsA3 handover

    A phone hands over when a neighbour beats its serving cell by offset + hysteresis for the whole time-to-trigger. Cell individual offsets let you prefer one layer, for example "use 5G whenever it is decent".

    reportFailures

    If SINR stays below −8 dB for T310 the radio link fails. Each failure is classified the way 3GPP mobility robustness optimisation does it: too late, too early, wrong cell or coverage hole. A quick return to the previous cell counts as ping-pong.
